# QA report — «Выдох» 1.8.1

## Автоматизированные проверки
- `npm run check`: пройдено — JavaScript-модули, Service Worker и JSON manifest.
- `npm test`: 72 passed, 0 failed.
- `src/styles.css` проверен через `tinycss2`: 1 176 узлов верхнего уровня, 0 parse errors.
- Статический HTTP smoke-test выполнен на отдельном временном порту: 14 критичных URL вернули HTTP 200, ответы прочитаны полностью.
- Проверены локальный профиль и отдельная страница настроек, позиция действия сброса после экспорта/импорта, 34 длинных совета для вкладки «Советы», 7 материалов о здоровье, 50 коротких подсказок главной, фильтры категорий, Canvas-renderer, пауза/возобновление, геометрия и кэширование фазовых градиентов.

## Производительность визуализатора
- Рендерер ориентируется на кадр около 16,67 мс (целевой режим до 60 FPS); фактическая частота зависит от браузера, экрана, устройства и его нагрузки.
- Градиенты Canvas создаются при изменении размеров, а не на каждом кадре.
- DPR ограничен 1.5; число частиц адаптивное — 64–132.
- Свечение частиц использует кэшированные спрайты; повторяемый `shadowBlur` у колец и орбит выключен.
- У активной сферы удалена анимация `background-position` и фазовые CSS-фильтры, меняющие размытие/оттенок каждый кадр. Цветовая динамика выполняется в Canvas; CSS использует в основном `transform` и `opacity`.
- Учтены скрытая вкладка и `prefers-reduced-motion`.

## Функции релиза
- 34 больших совета в «Советах», 7 отдельных health-материалов, 50 коротких советов на главной.
- Локальный профиль с именем и личной мотивацией; отдельная страница настроек; экспорт/импорт и сброс последним пунктом.
- Окантовки карточек/панелей усилены для различения поверхностей.

## Ограничения
- Физические устройства iPhone/Android не тестировались в этой среде. Перед публичным релизом нужно проверить анимации, звук, вибрацию, установку PWA, офлайн-обновление и миграцию пользовательских данных на настоящих устройствах.
- 60 FPS — цель рендерера, не гарантия на всех устройствах.
- Профиль локальный; регистрации, серверной базы и облачной синхронизации нет.
- Service Worker cache: `vydokh-redesign-1.8.1`.
