# «Выдох» 1.2.0 — Breath & Insight

Обновление развивает дыхательные практики, персональную статистику и библиотеку поддержки. Приложение остаётся статическим PWA без обязательного аккаунта, API и сторонних JavaScript-зависимостей. Основные пользовательские данные хранятся локально в браузере.

## Что нового в 1.2.0

### Дыхательные практики

- Пять практик: естественное дыхание, спокойный ритм, мягкое замедление, переключение внимания и ритмичная практика с необязательными задержками.
- Выбор продолжительности: 1, 3, 5 или 10 минут; выбранное значение можно сохранить для конкретной техники.
- Визуальная сфера с фазами, инструкцией, таймером и индикатором прогресса.
- Необязательные звуковые сигналы и вибрация при поддержке устройства и разрешении пользователя.
- Пауза, продолжение, досрочное завершение, избранное и история завершённых/прерванных сессий.
- После практики можно по желанию отметить силу тяги, эмоциональное состояние и заметку. Самооценка сохраняется локально и не трактуется как доказательство эффективности.
- Помощь при тяге плавно передаёт пользователя в короткую дыхательную сессию, а затем позволяет записать оценку после неё.
- Инструкция просит дышать без усилия и остановиться при головокружении или дискомфорте. Задержки дыхания необязательны.

### Статистика и личный прогресс

- Периоды: последние 7 дней, 30 дней и весь путь.
- Сравнение среднего значения с личной исходной точкой при условии, что используется одна и та же единица учёта.
- Неизвестные дни остаются неизвестными и не преобразуются в нулевое употребление.
- При отображении статистики учитываются записи календаря, контекст дневника тяги, практики и добровольная самооценка после практики.
- Можно увидеть отмеченные ситуации и эмоции, количество практик и личные оценки тяги до/после дыхания.
- Аналитика описывает собственные записи пользователя; совпадение триггера и тяги не доказывает причинность, а снижение субъективной оценки после практики не доказывает клинический эффект.
- Расчёт экономии опирается на пользовательские расходы и сравнимые измерения; при недостающих исходных данных оценка не показывается.

### Библиотека помощи

- Поиск, темы, фильтры по формату материала и ситуации.
- Короткие действия для момента тяги, самонаблюдение за триггерами, планирование, информация о симптомах отмены, поддержка после употребления и обращение к специалисту.
- Отдельный материал ВОЗ об отказе от электронных сигарет; медицинская помощь не смешивается с общими упражнениями для стресса.
- Источники: ВОЗ (включая пошаговую кампанию 2026 года), CDC и NHS. Тексты адаптированы своими словами, а не скопированы из источников.

## Медицинские границы контента

Дыхание описывается как вспомогательная техника, которая некоторым людям может быть полезна для стресса и переключения внимания; приложение не заявляет, что дыхание лечит никотиновую зависимость или гарантирует исчезновение тяги. Клиническое руководство ВОЗ 2024 года относится к прекращению употребления табака у взрослых. Оно не должно автоматически трактоваться как индивидуальное назначение для вейпинга. Для электронных сигарет библиотека ссылается на отдельную информационную страницу ВОЗ; подходящее лечение, препараты и местные службы пользователь обсуждает со специалистом.

Источники для самостоятельной проверки:

- [ВОЗ — Quit today: пошаговый план отказа от табака и никотина (2026)](https://www.who.int/campaigns/world-no-tobacco-day/2026/quit-today)
- [ВОЗ — клиническое руководство по отказу от табака у взрослых (2024)](https://www.who.int/publications/i/item/9789240096431)
- [ВОЗ — How to quit e-cigarettes?](https://www.who.int/news-room/questions-and-answers/item/how-to-quit-e-cigarettes)
- [CDC — 7 распространённых симптомов отмены и способы справляться с тягой](https://www.cdc.gov/tobacco/campaign/tips/quit-smoking/7-common-withdrawal-symptoms/index.html)
- [NHS — дыхательные упражнения при стрессе](https://www.nhs.uk/mental-health/self-help/guides-tools-and-activities/breathing-exercises-for-stress/)

Эти ссылки дают общую образовательную информацию, не заменяют персональную медицинскую консультацию и не означают, что перечисленные организации одобряют приложение.

## Быстрый запуск

Открытие через `file://` не подходит, поскольку приложение использует ES-модули. Запусти HTTP-сервер из каталога, в котором лежит `index.html`:

```bash
python3 -m http.server 8000
```

На Windows, если `python3` не распознаётся, попробуй:

```powershell
py -m http.server 8000
```

Открой <http://localhost:8000>. Сервер нужен только для отдачи статических файлов; отдельный backend не требуется.

## Проверка проекта

```bash
npm run check

```

Внешние npm-пакеты не требуются. Node.js нужен только для команд проверки и тестов; для запуска приложения достаточно Python или любого статического HTTP-сервера.

## Данные, миграция и приватность

- Текущие данные хранятся в `localStorage` в ключе `vydokh.v4`; эта итерация расширяет интерфейс и уже существующие поля схемы v4, поэтому дополнительная миграция схемы не нужна.
- При первом запуске новая версия может перенести данные из `vydokh.v3`, `vydokh.v2` или исходного `vydokh.v1`. Старые ключи автоматически не удаляются.
- История практик, избранное, длительность, звуковые/вибрационные настройки, записи тяги, недельные обзоры и заметки входят в локальное состояние и резервную копию.
- Перед серьёзным обновлением рекомендуется сделать экспорт через «Профиль → Экспортировать данные».
- При смене единицы учёта значения не пересчитываются автоматически и не переименовываются. Сравниваются только данные, записанные в той же единице.
- Неизмеренный день не считается нулевым употреблением в аналитике; пользователь может явно отметить день без употребления. Отметка сохраняется локально.
- `localStorage` не синхронизируется автоматически между устройствами. Сервер не получает дневник, практики и статистику в обычном режиме.

## PWA, звук и вибрация

- Для Service Worker нужен HTTPS либо `localhost`/`127.0.0.1`.
- Внешние звуки генерируются локально при включённой настройке; браузер может требовать пользовательское действие для запуска аудио.
- Вибрация зависит от устройства и браузера. Если API не поддерживается, практика остаётся полностью функциональной без неё.
- `prefers-reduced-motion` отключает необязательное движение.
- Локальные напоминания ограничены возможностями браузера. Push для закрытого приложения не подключён без отдельного сервера.

Подробные результаты и ограничения проверки — в [QA-REPORT.md](QA-REPORT.md).

- `npm run check` — синтаксис JavaScript-модулей и Service Worker, JSON-манифест.

Поэтому перед публичным выпуском необходим ручной проход по сценариям в браузере, затем на физических iPhone/Android — особенно для PWA, звука, вибрации и жизненного цикла Service Worker.
