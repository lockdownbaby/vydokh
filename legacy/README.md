# Выдох — PWA для отказа от вейпа

Серия дней без никотина, счётчик затяжек за сутки, счётчик сэкономленных денег с целью накопления, календарь, 6 дыхательных техник, режим «Хочется затянуться», 26 советов и 50 причин бросить (случайно показываются на главном экране). Есть настоящие push-уведомления через собственный сервер.

## Файлы

- `index.html`: всё приложение (стили, логика, контент)
- `config.js`: адрес push-сервера
- `manifest.webmanifest`: описание PWA
- `sw.js`: service worker (работа без интернета, приём push)
- `icon-*.png`: иконки
- рядом лежит папка `vydokh-push`: сервер для push-уведомлений

## Как запустить

PWA работает только по HTTPS. Самые простые бесплатные варианты:

1. **GitHub Pages**: создай репозиторий, загрузи файлы из этой папки в корень, включи Pages в настройках.
2. **Netlify Drop** (app.netlify.com/drop): перетащи папку в окно браузера.
3. **Cloudflare Pages**: подключи репозиторий или загрузи папку.

Папку `vydokh-push` на сайт выкладывать не нужно: это отдельный сервер.

## Как установить на iPhone

1. Открой адрес приложения в Safari.
2. Нажми «Поделиться» и выбери «На экран „Домой“».
3. Запускай с иконки: приложение откроется во весь экран.

## Экономия денег

В карточке «Сэкономлено» на главном экране (или в «Настройки → Деньги») укажи, сколько в неделю уходило на жидкости, картриджи и устройства. Сумма растёт каждый час.

- Если указано, сколько затяжек в день было раньше, экономия считается пропорционально сокращению затяжек: день с половиной прежнего числа затяжек даёт половину дневной суммы.
- Если не указано, учитываются только дни без затяжек.
- Можно поставить цель накопления (название и сумма). Когда она достигнута, приложение поздравит.

## Push-уведомления

Без сервера напоминания приходят, только пока приложение открыто. Чтобы они приходили при закрытом приложении:

1. Разверни сервер из папки `vydokh-push` по инструкции в её README (около 10 минут, бесплатно).
2. Впиши адрес сервера в `config.js` и заново выложи сайт.
3. На iPhone установи приложение на экран «Домой» и включи «Настройки → Напоминания».

На iPhone push работает только из установленного приложения (iOS 16.4 и новее).

## Данные

Заметки, календарь и число затяжек хранятся в `localStorage` на устройстве. Если включён push, серверу отправляются только подписка, время напоминаний, часовой пояс, момент последней затяжки, расходы в неделю и валюта. Если очистить данные сайта в Safari, история пропадёт.

## Обновление

После правок в файлах увеличь номер в `const CACHE = 'vydokh-v2'` в `sw.js`, иначе у пользователей останется старая версия.

## Важно

Приложение не заменяет консультацию врача. Горячие линии и номера в разделе «Советы → Помощь» проверь на актуальность для своей страны.
